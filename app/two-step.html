Two-step sign-in for developers

The developer pages can change everyone's data, so they need a code from an authenticator app on your phone as well as your password. You set this up once.

  1. Install an authenticator app if you don't have one, e.g. Google Authenticator, Microsoft Authenticator, or the Passwords app on an iPhone.

Enter the 6-digit code from your authenticator app to open the developer pages.
