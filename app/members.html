Members Table

One row per person, each with their own email address. Membership: only Active members can use the app; Inactive members see the message set in Settings > App settings. Sunday Doubles: only Active members with Yes see the Sunday Doubles pages and get its emails. App Access shows whether the member has joined: new members are Pending STA Member App Invitation until you click Send Invite.

Upload the club's current member list

Upload the club's list of current members as a CSV or TSV file (in Excel or Google Sheets: File > Download/Save as CSV). It needs an Email column and/or First and Last name columns, like the membership export. Members in the file are marked Active; everyone else is marked Inactive. You'll see exactly what will change before anything is saved.
